CPU Visualizer (Haskell + WASM)

  • マウスホイール: 回路ビュー ズーム
  • ドラッグ: 回路ビュー 移動
  • パネル h2 ドラッグ: パネル 移動
  • パネル 角ドラッグ: パネル リサイズ
  • Ctrl+ホイール (メモリ上): メモリ フォントズーム
  • Space: 1ステップ実行
  • R: 連続実行 / P: 一時停止

論理回路シミュレーションは 純粋 Haskell で実装。
GHC WASM バックエンドでコンパイルしてブラウザで動作します。

ビルド方法:

# GHC WASM のインストール
make install-wasm-ghc
source ~/.ghc-wasm/env

# WASM ビルド
make wasm

# サーバー起動
make serve   # → http://localhost:8080
